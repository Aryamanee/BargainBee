# BargainBee
The Bargain Bee Client
Use in tandem with the [server](https://github.com/Aryamanee/BBServer)

##What is BargainBee?
BargainBee is a full-stack cross-platform marketplace application for buying and selling used goods. 

##Why is BargainBee different than the other marketplace applications?
BargainBee uses a scrolling format unlike most other marketplace applications out there. Potential buyers can scroll through products which are likely to suit their preferences rather than endlessly searching for what they want.
